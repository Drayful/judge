# Проверка рабочего процесса турнира — 27.09.2026

## Функции по исходному списку

1. **Расписание по дням.** Сформированные потоки отображаются в раскрывающихся днях внизу страницы. Есть фильтр даты и времени и кнопка сброса фильтра. Выбранные поля формирования сохраняются в браузере отдельно для каждого турнира, включая отправку формы без изменения значений.
2. **Награждение.** Длительность задаётся после потока; последующие потоки того же дня смещаются на изменение длительности. Переход за полночь отклоняется без частичного сохранения. Интервал награждения виден на странице, в стартовом листе и программе.
3. **Excel.** Стартовый лист скачивается отдельно для выбранного дня; потоки других дней и без даты в него не попадают. Программа содержит отдельные листы по дням.
4. **Редактирование оценки.** Поля изменения и возврата находятся сверху в подробностях. Для A/E редактируется исходная сбавка, а не результат её вычитания из базы.
5. **Е.** Итог округляется до двух знаков перед расчётом общего результата. Требование о тысячных заменено последним уточнением пользователя.
6. **Доработка и история.** Возвращённый судья выделен фиолетовым, расхождение — красным. История хранит изменения «до → после». Ввод не затирается фоновым обновлением, в том числе если ответ сервера пришёл уже после начала редактирования.
7. **Список судей.** Excel с колонками «ФИО» и «Школа» загружается для отдельного турнира. Выбор из списка связывает судью с планшетным аккаунтом; имя сохраняется вместе с оценкой. Если список турнира загружен, перед отправкой оценки требуется выбор судьи.
8. **Одна школа.** Совпадение школы судьи и участницы отмечено отдельным янтарным индикатором.
9. **Погрешность.** Порог между крайними оценками и допустимое отклонение от арифметической средней задаются на уровне турнира.
10. **Неотправленные оценки.** Ввод доступен из истории и раскрывающейся панели текущего выступления в Live, включая официальные средние. Нужен однозначно определяемый судейский аккаунт; при конфликте назначений сохранение отклоняется. Для БП учитывается работа DA-судьи в панели DB.
11. **Просмотр для главного судьи.** Доступны оценки, история, исправление, возврат, подтверждение, отдельные DB/DA, таймер, музыка, состав команды, статусы и просмотр протестов. Страница обновляется, не меняя активный поток. Подтверждение из просмотра не продвигает очередь даже у секретаря. Главному судье запрещены Live и операции с очередью, включая изменение протестов, которое меняет статус выступления.
12. **Очередь.** Возврат к предыдущей участнице сохраняет порядок; при уже начавшейся работе с текущей участницей возврат блокируется. Автоматического переключения потока нет. Закрытие — зелёная кнопка, повторное открытие — красная.
13. **Протоколы по годам.** Есть Excel и отдельная печатная страница выбранного года. При печати всех годов каждый начинается с новой страницы. Места считаются в соответствующем возрастном соревновательном пуле, как в Excel. Участники без даты рождения печатаются отдельно без возрастного места.
14. **LINE, TIME и табло.** На LINE доступна отмена действия. Автозавершение после TIME Stop оставлено в комментарии. Показ оценки на табло можно отменить без удаления результата и утверждения.

## Проверки и границы

- PHP/Laravel: полный набор тестов, включая новые сценарии отсутствующих оценок, БП, независимого просмотра, печати и выгрузок по дням.
- JavaScript: тесты защиты от замены формы во время редактирования и совместимости обычного обновления.
- Production-сборка Vite и компиляция Blade.
- Это локальная программная проверка, не очный прогон соревнования на реальных планшетах. Музыкальные файлы, принтер и визуальную работу конкретных устройств нужно проверить на стенде.
- Новых миграций нет. При публикации нужны актуальные собранные CSS/JS и обновление кэша представлений. В рамках этой доработки коммит, push и обновление сервера не выполнялись.
